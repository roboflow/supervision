# Contributing to Supervision 🛠️

Thank you for your interest in contributing to Supervision! We are actively improving this library to reduce the amount of work you need to do to solve common computer vision problems.

Please read and follow our [Code of Conduct](../code_of_conduct.md). It describes the expected behavior for everyone who takes part in the project.

!!! warning "You must sign the CLA"

    Every contributor is obliged to sign the Contributor License Agreement (CLA). When you open your first pull request, the `cla-assistant` GitHub bot asks you to sign it. We can only review and merge pull requests from contributors who have signed.

!!! tip "Contribute from a personal fork"

    We prefer pull requests from a fork in your **personal** GitHub account. GitHub does not let maintainers push to a pull request branch that lives in an organization-owned fork, so we could not fix a small issue, rebase, or finish the last details for you. Keep **Allow edits by maintainers** enabled when you open the pull request.

## What we welcome

- New features, within the scope described below.
- Improvements to the documentation and new [cookbooks](development.md#cookbooks).
- Bug reports and feature requests.
- Better test coverage.

## Contributing features ✨

Supervision provides generic utilities that solve problems across many projects. Counting objects that cross a line anywhere on an image is a common problem in computer vision. Counting objects that cross a line 75% of the way through is much less useful.

Before you build a new feature, open an Issue to discuss it, so the community and maintainers can weigh in early.
